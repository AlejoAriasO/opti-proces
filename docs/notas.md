Cómo abrir tu aplicación
Abre una terminal nueva (PowerShell o CMD) — importante, para que reconozca Node.js — y ejecuta:

cd c:\Users\alejo\OneDrive\Escritorio\opti-proces
npm start
Espera unos segundos hasta que aparezca algo como Local: http://localhost:4200/. Abre esa dirección en Chrome o Edge.
